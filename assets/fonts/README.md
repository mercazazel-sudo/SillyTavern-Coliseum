# Шрифты

Локальные woff2, чтобы расширение ничего не тянуло из интернета. Правила `@font-face` лежат в `../../fonts.css` и подключаются из `style.css`.

| Семейство | Начертания | Где используется |
|---|---|---|
| Cormorant Garamond | обычный и курсив, 400–600 | текст постов, интерфейс |
| Forum | 400 | заголовки |
| Playfair Display | курсив 500 | имена в чате |

Подмножества: `cyrillic`, `cyrillic-ext`, `latin`, `latin-ext` (браузер сам берёт нужное по `unicode-range`).
Источник: Google Fonts. Лицензия всех трёх SIL Open Font License 1.1, тексты в `licenses/`.
